# P5-4 sequence（前一球與記憶長度；建模期 2023–2024 例行賽；四組分開）

**結論一句話**：①**前一球的球種有影響，方向與 P5-3 一致**：當前球與前一球「不同球種」時，相對「前一球同球種」，每次揮棒的揮空率較低（常見 −3 到 −9 個百分點）、每球平均價值較高（對投手較不利，約 +0.01 到 +0.02 分／球）。②**預測上，前球資訊的增益極小**：在控制投手與打者個體效應後，右投手的最佳記憶長度是 **1 顆**（增益約 +0.0002 到 +0.001 logloss，logloss 約 1.2），左投手是 **0 顆**（沒有可用的增益）。**證據等級：①建模期已偵測到、尚未經 2025 確認（目前為「中」以下）；②結論為「記憶 1／0，增益很小」。**

## 依據（A7 #118–#120、A8 #121–#125；表見 `docs/research/summaries/prev1_regression.txt`、`memory_ladder.txt`、`hgb_robustness.txt`）
- **前一球迴歸（A7，S3：投手與打者固定效應，參考＝前一球同球種）**：揮空率 201 個 (組, 球種, 前一球球種) 中 36 個的 99% 區間不含 0 且 ≥1 個百分點（純偶然預期約 2）；平均價值 240 中 20（預期 2.4）；揮棒率 240 中 26（預期 2.4）。例：RvR 滑球在前一球為四縫線速球之後 −3.8 個百分點 [−5.6, −2.1]、RvR 四縫線速球在滑球之後 −3.2 [−4.6, −1.8]、RvR 橫掃球在沉降球之後 −6.4 [−9.4, −3.4]；平均價值：RvR 四縫線速球在滑球之後 +0.0109 分／球 [+0.0030, +0.0189]。（「OTHER」是球數不足而併在一起的稀有球種，不解讀。）沒有分季重複與 S4，所以這一項的證據比 P5-3 弱。
- **記憶長度階梯（A8，邏輯迴歸＋投手與打者個體效應，訓練 2023、留出 2024；規則：最小的 m，使 m→m+1 的邊際增益 95% 區間上界 < 0.0003）**：
  - RvR：base→m1 +0.00023 [+0.00005, +0.00039]，m1→m2 +0.00018 [+0.00009, +0.00026]（上界 < 0.0003）→ **m＝1**。
  - RvL：base→m1 +0.00105 [+0.00085, +0.00124]，m1→m2 −0.00054 → **m＝1**。
  - LvR：base→m1 −0.00012 [−0.00051, +0.00025]（上界 < 0.0003）→ **m＝0**。
  - LvL：base→m1 −0.00094 [−0.00157, −0.00036]（變差）→ **m＝0**。
  - 沒有個體效應時（#122）：RvR base→m1 +0.00057、RvL +0.00089，加入個體效應後約減半——序列特徵確實有一部分是在替投手身分代言（見合成世界測試）。
  - 期望得分均方誤差的增益多數區間含 0，沒有一組顯示序列資訊能改善「每球期望得分」的預測。
- **邏輯迴歸不是好的基準模型**：同一組資料，提升樹（固定 150 棵、關閉早停）的 logloss 在 RvR 為 1.1345，邏輯迴歸 1.2226；差距來自位置等非線性。因此「序列增益很小」是相對於「邏輯迴歸 ＋ 個體效應」的結論。
- **提升樹的序列增益不可解讀**（#123–#125，三個種子）：RvR 為負（−0.012、−0.014、−0.023）、RvL 為 +0.016、+0.042、+0.0002、LvR 與 LvL 為 +0.089、+0.123（三個種子完全相同），而且小組的 base 變體嚴重過度擬合（LvL base logloss 1.378，比 full 的 1.256 還差）。符號不一致或大小不合理 → 依計畫報告「不穩定」，**不用於結論**。

## 對 P6 的意義（暫記）
①連投與前一球的影響存在但小：每球約 0.01 分、預測 logloss 約千分之一；②P6 若要用提升樹估計機率，必須先解決小組過度擬合（早停、正則化、更少棵數）並以留出集校準；③左投手資料量少（LvL 約 10 萬球），序列資訊在現有樣本下不可用。

## 限制
邏輯迴歸基準偏弱；個體效應以稀疏單熱編碼（≥200 球的個體）；A7 沒有分季重複；2026 尚未檢驗。
