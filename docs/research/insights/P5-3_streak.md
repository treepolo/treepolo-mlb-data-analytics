# P5-3 streak（連投；建模期 2023–2024 例行賽；四組分開；以投手分群）

**結論一句話**：在控制投手、打者、球數與同球種已投球數之後，**連續投同一球種的第 2、3 顆，對投手更有利**——打者較少揮棒、揮棒時更常揮空、較少打成界內球、不揮棒時更常被判好球，每球的平均得分價值下降約 0.01 分；這與一般預期的「連投衰減」**方向相反**。**證據等級：建模期已偵測到（見下），尚未經 2025 樣本外確認，因此目前不能標為「強」。**

## 依據（A5 #18–、A6 #20–#115、A10 #116、A10b #117；逐格表見 `docs/research/summaries/`）
- **預先登記的偵測準則**（計畫 2.3；S3 的 99% 區間不含 0、S4 同號且至少一半、2023 與 2024 同號且各至少 1/3、實務大小、分群數足夠）下，偵測到的格數／檢定格數（純偶然預期約 0.5–0.6）：每次揮棒的揮空率 **12／52**、揮棒率 7／60、不揮棒時被判好球率 15／56、界內球率（每次揮棒）14／52、平均價值 8／60、界外率 1／52。**全部偵測到的效應方向一致**：揮空率上升、揮棒率下降、好球判決上升、界內球率下降、平均價值下降。
- **大小（S3，99% 區間；k＝2）**：揮空率——RvR 四縫線速球 +2.3 個百分點 [+1.2, +3.5]、RvR 滑球 +2.8 [+1.2, +4.4]、RvR 橫掃球 +5.6 [+3.2, +8.0]、RvL 四縫線速球 +2.9 [+1.7, +4.1]、RvL 滑球 +3.6 [+1.5, +5.6]、RvL 變速球 +3.5 [+1.4, +5.6]；k＝3 時滑球 +5.6（RvR）、+7.6（LvR）。平均價值：RvR 四縫線速球 −0.0098 分／球 [−0.0168, −0.0029]、RvR 滑球 −0.0086、RvR 橫掃球 −0.0155，LvL 四縫線速球 −0.018。
- **沉降球（SI）沒有偵測到**（RvR 揮空率 −0.9 個百分點，區間含 0），切速球（FC）、曲球（CU）大多也沒有；LvL 組樣本太少（多格因單季球數不足無法做分季重複，準則 3 判為未達成）。
- **規格階梯（S2→S3→S4→S5）**：S4（同一投手同一場比賽內比較）的點估計多半小於 S3（保留約 35%–95%，k=2 多在 70% 以上；例：RvR 滑球 k=2 +0.028→+0.027、k=3 +0.056→+0.043；RvR 四縫線速球 k=3 +0.024→+0.008）；加上前一球結果、位置、球速（S5）後幾乎不變，所以**不是**「投手連投時把球投到不同位置或球速變了」造成的。符號翻轉（S2／S4 與 S3 反號）佔全部估計的 17%（揮空率）、全體 15%，低於計畫的停止門檻 20%。
- **診斷（安慰劑，只當診斷）**：
  - 同一點比較 S1（只用球序與球數分層，A10）：安慰劑平均 +2 到 +6 個百分點，**比觀察值還大**——S1 在真實資料上有結構性的正偏誤（投手風格與打席組成），所以 **S1／原始曲線的結果不用於任何判斷**。
  - 迴歸 S3（A10b）：在打席內把球種、是否合格、數值一起打亂後，安慰劑中位數 k＝2 為 +0.4 個百分點、k＝3 為 +1.0 個百分點，觀察值中位數 +2.2、+2.4，差 +2.1、+1.9；k＝2 有 13／26 格的差超過安慰劑標準差 2 倍，k＝3 只有 3／26。**S3 的效應大部分不是方法造成的，但 k＝3 的結論要比 k＝2 保守**（安慰劑本身有約 +1 個百分點的殘餘）。這個診斷工具在合成世界通過已知答案測試（零效應≈0、有效應時差距明顯、球種危險率不同時仍≈0）。

## 偏離預先登記之處（誠實記錄）
1. `hr_per_pitch` 的實務大小門檻 1 個百分點不可能達成（全壘打基礎率約 0.9%），所以預先登記的準則下 0 格偵測到，這**沒有資訊**；事後（post hoc）改用 0.2 個百分點：偵測到 3／60 格，全為負（重複投四縫線速球的全壘打率較低：LvL k=2 −0.65 個百分點、LvR k=3、RvL k=2），表只在 `docs/research/summaries/streak_hr_per_pitch_posthoc_0.002.txt`，標為事後分析。
2. 5.0 之後新增了「迴歸安慰劑」（A10b）作為 S3 的診斷（`streak_regression` 版本 2）；它沒有碰 2025、2026。
3. `foul_per_swing` 的符號翻轉率 29%（超過 20%），這個比率的結果標為「不穩定」，不下結論；全體比率 15% 沒有觸發停止條件。
4. 準則 3 需要兩季各自的估計；單季球數不足的格（多為 LvL 與稀有球種）依規則算「未達成」，不代表沒有效應。

## 限制
線性機率模型（單位為機率的百分點）；歷史上的選擇偏誤（捕手叫球、投手當下狀態）無法完全排除，S4 只控制了「同一投手同一場比賽」；k≥4 只描述不下結論；各投手的效應異質性沒有分析；2026 的定義與規則改變尚未檢驗。
