# P5-2 describe（建模期 2023–2024 例行賽，描述性；不做「偵測」判斷）

**結論一句話**：各球種的揮空率、全壘打率差異很大且穩定，但在同一情境下不同球種的**平均得分價值**差異多半小於雜訊（456 組球種配對只有 14 組超過 2.58 個標準誤，純偶然預期約 4.6 組；最大差 0.03 分／球）。
**證據等級**：不適用（描述；歷史上發生的結果，不是改投別的球會怎樣；位置是實際進壘點，不是瞄準點）。

## 依據（run：A1 #4、A2 #15、A3a #16、A3b #12、A4a #11、A4b #17）
- **得分期望值表**（A1）：288 個狀態全部有資料、最小 n＝37；RE(0-0、無人出局、壘空)＝0.499、滿壘無出局 2.283、一出局壘空 0.267、兩出局壘空 0.101，與 Savant 對照見 run #4 第三節。
- **球種輪廓（A2，四組各自，球數合併後的加總）**：每次揮棒的揮空率 SL 0.31–0.33、CH 0.28–0.31、CU 0.29–0.30、ST 0.26–0.32、FF 0.18–0.21、SI 0.12–0.13；全壘打率（每球）0.5%–1.0%（CH 在 RvR 0.98%、FF 0.9%、SI 0.5–0.8%）。平均價值在 ±0.006 分／球內；RvR 的 FC（−0.0053）、SI（−0.0043）、ST（−0.0034）、FF（−0.0030）、SL（−0.0027）對投手較有利，RvL 的 SI（+0.0041）、ST（+0.0029）、CU（+0.0028）對打者較有利（區間見 run #15 的 `value_lo/hi`）。
- **同一情境內球種差異（Q5）**：左右手組×球數共 456 組球種配對（每格 n≥2000），超過 2.58 個標準誤的 14 組；最強的是 LvL 1-2 球數 FF 對 SL（+0.031 分／球，z＝4.2）。結論：**沒有證據顯示在同一情境下，球種之間的平均價值有一致、可操作的差距**（解析度約 0.01 分／球）。
- **揮棒分項（A2，Q6）**：有值比例——擊球仰角 33%、球棒速度 32%（2023-07-14 前整段沒有）、`miss_distance` 7.5%（只有揮空）。揮空時球與球棒的距離（RvR）：FF 平均 1.06 英寸、CH 3.63、SL 4.97——滑球與變速球是「錯得更多」才揮空，四縫線速球是「差一點」。球棒速度（RvR）：FF 69.9、SL 69.0、CH 71.3 mph（平均值混合了揮空、界外與界內球）。
- **位置（A3a、A3b、圖）**：全壘打率集中在好球帶中段偏內側的兩個格子（x 箱 1–2、z 箱 2–3，單格最高約 2.5%）；揮空率最高在好球帶下緣與外側（z 箱 0，最高約 0.87，樣本量見圖）。圖在 `docs/research/figures/A9_location_*`（四個左右手組各兩張）。

## 限制
