# P5-7 extra study X1（2023–2026 全期間；分組交叉驗證；沒有乾淨檢驗集）

**結論一句話**：把四個球季合在一起，建模期（2023–2024）的連投效應**方向與大小大致不變，只是區間變窄**（標準誤約為建模期的 0.7 倍）；序列記憶長度在全期間資料下**四組都是 1 顆**（含建模期選 0 的 LvR），增益仍然很小（約 +0.0007 到 +0.0009 logloss）。**這個研究沒有乾淨檢驗集，只能內部交叉驗證，其準確度不得與 P5-6 的 2025／2026 檢驗結果並列比較。**

## 限制
- 沒有乾淨檢驗集；2026 的規則／定義改變被混進四季平均，好球判決類尤其如此。
- 增益極小（<0.001 logloss），「記憶 1」代表「前一球有一點資訊」，不代表序列對預測有大用。
- 三份迴歸（揮棒率、全壘打率、平均價值）因四季球數超過預設的 200 萬列上限，把 `max_rows` 提高到 350 萬（容量參數，不影響結果）。
